这些文件是 Ultralytics 文档网站的“前端皮肤”和交互逻辑，负责：
    页面样式（表格、代码块、 banner 等）
    主题切换（自动跟随系统亮/暗）
    顶部公告栏（HUB 广告）
    源码文件显示（最后修改日期）
    嵌入到父页面的通信（postMessage）

这些是 “文档网站的颜值和交互”，删了不会报错，但页面会变丑、功能会失灵。

📌 每个文件作用与是否可删：

文件名	                作用	                                                    是否可删
style.css	            表格 GitHub 风格、代码块滚动、内容宽度、banner 背景	        ❌ 不建议删（影响颜值）
main.html	            顶部公告栏（HUB Cloud Training 广告）	                    ✅ 可删（去掉广告）
source-file.html	    页面底部显示“最后更新/创建日期”	                            ✅ 可删（但用户看不到更新时间）
extra.js	            自动亮/暗主题、语言切换时重新应用主题、嵌入 iframe 通信	        ❌ 不建议删（主题会失效）

✅ 可以删的（极简部署）：
    main.html               → 去掉顶部广告横幅。
    source-file.html        → 去掉页面底部的日期信息。

❌ 不建议删的：
    style.css               → 删掉后表格、代码块、banner 全部变丑。
    extra.js                → 删掉后主题切换失效，嵌入页面通信断裂。

这些文件 不影 YOLO 核心功能，但 决定你的文档网站“长什么样、好不好用”。
如果你做 私有部署或极简内网文档，可以 只保留 style.css 和 extra.js，去掉广告和日期显示。
