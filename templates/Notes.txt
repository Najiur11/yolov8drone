这两个文件是一个 完整的 Web 演示系统的前端入口页面，分别对应：
        index.html：主界面（上传图像/视频、实时展示识别结果）
        login.html：登录页（用户名+密码，防止未授权访问）

这是 “YOLO Web 演示的门户”，删了页面就打不开，用户无法上传图像或登录。

📄 文件 1：index.html（主界面）
区域	                作用	                                            关键注释
用户信息栏	        显示当前登录用户 & 退出按钮	{{ username }}          由后端模板渲染
状态指示器	        实时显示 Socket 连接状态、处理状态	                颜色变化：绿=已连接，红=未连接
控制面板	            上传图像/视频、选择任务类型	                        三个按钮：检测图片 / 动态识别 / 路径分析（跟踪）
进度条	            视频处理时显示上传/推理进度	                        仅视频任务出现
显示区域	            左右分栏：原始图像 vs 处理结果	                    图像/视频帧实时回显

📄 文件 2：login.html（登录页）
区域	                作用	                                    关键注释
登录表单	            POST 提交到 /login	                    字段：username、password
错误提示	            模板变量 {{ error }}	                    用户名或密码错误时显示
默认账号	            页面上直接给出	                            方便首次使用（可后续删除）
样式	                内嵌 <style>	独立登录页，不使用外部           style.css

✅ 可以删的场景：
    你只提供 API 或命令行工具，不需要 Web 演示。
    你已有自己的前端，不需要这个默认界面。
    你不需要 用户登录（如内网使用）。

❌ 不建议删的场景：
    你提供了 Web 演示地址（如 http://localhost:5000）。
    你希望用户 上传图像/视频并实时查看 YOLO 结果。
    你需要 登录保护（防止未授权访问）。
