这两个文件是一个 完整的前端 Web 应用，用于：
    上传图像/视频
    与后端 Socket.IO 服务实时通信
    展示处理结果（图像或视频帧）
    显示连接状态、处理状态、进度条
    支持目标检测/跟踪任务

    这是一个 “YOLO Web 演示前端”，删了不会报错，但你的 Web 演示就打不开了。

📁 文件 1：script.js（核心交互逻辑）

功能模块	                    作用	                                    关键注释
initSocket()	            建立 Socket.IO 连接，监听后端事件	        自动重连、心跳保活、支持图像/视频处理结果回传
processImage()	            上传图像并触发处理	                        将图像转为 Base64 发送给后端
processVideo()	            上传视频并触发处理/跟踪	                    支持跟踪开关，带进度条
stopProcessing()	        中止处理	                                发送停止信号
updateProgress()	        实时更新进度条                         	用于视频处理
updateConnectionStatus()	显示连接状态（绿/红）	                    控制按钮是否可用
updateProcessingStatus()	显示处理状态（处理中/完成/错误）	            颜色区分状态

📁 文件 2：style.css（视觉样式）

功能模块	                    作用	                                关键注释
全局样式	                    渐变背景、圆角卡片、阴影	                现代感 UI
状态指示器	                连接状态、处理状态	                    左上角实时状态标签
控制面板	                    上传按钮、处理按钮、进度条	            按钮颜色区分功能（蓝=处理，橙=跟踪，红=停止）
显示区域	                    图像/视频预览	                        自适应大小，最大高度 400px
响应式布局	                支持手机/平板	                        992px 以下切换为上下布局
